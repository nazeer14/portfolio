# Shaik Nazeer Portfolio — refreshed files

## Files
- `index.html` — semantic page structure and portfolio content
- `style.css` — responsive layout, colors, typography, project preview styles, and motion
- `script.js` — mobile navigation, scroll progress, reveal effects, project filters, and email form

## Run locally
Keep all three files in the same folder, then open `index.html` in a browser. For a more realistic local server, use VS Code Live Server.

3. Confirm whether DigitalPrime belongs in E-commerce; the source Projects document lists it in that section but gives no description.

## Design direction
Warm off-white background, deep green typography, restrained lime accent, editorial headings, responsive project cards, and simple motion. Reduced-motion preferences are respected.
